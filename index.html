Hướng Dẫn Lưu Dữ Liệu Vĩnh Viễn 100%

Dữ liệu của bạn đã tự động lưu vào Trình Duyệt! Mọi thao tác thêm khách hàng, tạo dịch vụ, ghi nợ đều được hệ thống lưu tức thì vào LocalStorage trên máy tính/điện thoại này.

3 Phương Án Để Lưu Trữ Vĩnh Viễn Không Bao Giờ Mất:

1 Tải File HTML về Máy Tính / Điện thoại

Bấm nút "Tải xuống" ở góc phải trên cùng màn hình. Lưu file index.html vào máy tính. Mỗi lần cần dùng, chỉ cần double-click mở bằng Chrome / Edge / Safari. Dữ liệu sẽ tiếp tục lưu trữ tại máy của bạn mãi mãi.

2 Sao Lưu File Dự Phòng JSON Hàng Tuần

Sử dụng nút "Sao lưu (Export JSON)" trên menu trái để tải file backup CRM_Backup_YYYY-MM-DD.json. Bạn có thể khôi phục lại toàn bộ dữ liệu trên bất kỳ máy tính hoặc điện thoại mới nào bằng nút "Khôi phục (Import JSON)".

3 Đưa Lên Server Free (GitHub Pages / Netlify)

Nếu muốn truy cập website từ cả điện thoại lẫn laptop qua link riêng, bạn chỉ cần up file HTML này lên Netlify Drop hoặc GitHub Pages hoàn toàn miễn phí.
